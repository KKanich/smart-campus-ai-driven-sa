# Expense Calculator

A lightweight command-line and library tool for recording and summarizing personal or team expenses in JSON format.

## Setup

Requires Python 3.9+. No external packages are required.

## Usage

```bash
python3 -m expense_calc.cli add "Team lunch" 24.50 food 2026-11-10
python3 -m expense_calc.cli summary
python3 -m expense_calc.cli export csv
```
